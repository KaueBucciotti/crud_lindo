# Cadastro de Associado – Calcinha Preta



## ✨ Descrição

Bem-vindo ao projeto **Cadastro de Associado** da **Calcinha Preta**! Este é um sistema simples para gerenciar os associados da comunidade oficial de fãs da banda. A interface é moderna e foi projetada para facilitar o cadastro, atualização, e remoção de associados.
